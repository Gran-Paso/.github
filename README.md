# .github

## Descripción del Proyecto

Este es el repositorio especial `.github` de la organización **Gran-Paso**. Los repositorios con este nombre tienen un propósito especial en GitHub y sirven para configurar aspectos a nivel de toda la organización.

### ¿Para qué sirve este repositorio?

1. **Perfil de la Organización**: Si se crea una carpeta `profile/` con un archivo `README.md`, ese contenido se mostrará en la página principal de la organización en GitHub.

2. **Archivos de Salud Comunitaria Predeterminados**: Este repositorio puede contener archivos que se aplicarán como predeterminados a todos los repositorios de la organización, tales como:
   - `CONTRIBUTING.md` - Guía para contribuidores
   - `CODE_OF_CONDUCT.md` - Código de conducta
   - `SECURITY.md` - Política de seguridad
   - `SUPPORT.md` - Información de soporte
   - `FUNDING.yml` - Configuración de patrocinio

3. **Plantillas de Issues y Pull Requests**: Puede contener plantillas predeterminadas que se usarán en todos los repositorios de la organización.

4. **Flujos de Trabajo Reutilizables**: Puede almacenar GitHub Actions y workflows que pueden ser reutilizados por otros repositorios de la organización.

### Organización Gran-Paso

Este repositorio pertenece a la organización Gran-Paso y sirve como punto central de configuración para todos los proyectos de la organización.
