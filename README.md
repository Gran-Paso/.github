# Gran-Paso

## ¿Qué es Gran-Paso?

Gran-Paso es una organización en GitHub dedicada a proyectos colaborativos de desarrollo de software. Este repositorio `.github` contiene los archivos de configuración y documentación que se aplican a todos los repositorios de la organización.

## Propósito de este repositorio

Este repositorio especial `.github` sirve como punto central para:

- 📄 **Archivos de comunidad predeterminados**: Plantillas y guías que se aplican automáticamente a todos los repositorios de la organización que no tengan sus propios archivos
- 👤 **Perfil de la organización**: El archivo `README.md` en el directorio `profile/` se muestra en la página principal de la organización
- 📋 **Plantillas de issues y pull requests**: Formatos estandarizados para reportar problemas y proponer cambios
- 📜 **Políticas y lineamientos**: Código de conducta, guías de contribución y políticas de seguridad

## Estructura del repositorio

```
.github/
├── README.md                    # Este archivo
├── profile/
│   └── README.md               # Perfil público de la organización
├── ISSUE_TEMPLATE/             # Plantillas para issues
│   ├── bug_report.md
│   └── feature_request.md
├── PULL_REQUEST_TEMPLATE.md    # Plantilla para pull requests
├── CONTRIBUTING.md             # Guía de contribución
├── CODE_OF_CONDUCT.md          # Código de conducta
├── SECURITY.md                 # Política de seguridad
└── FUNDING.yml                 # Configuración de patrocinio
```

> **Nota**: No todos estos archivos pueden estar presentes actualmente. Se irán agregando según las necesidades de la organización.

## Cómo contribuir

¡Las contribuciones son bienvenidas! Si deseas contribuir a los proyectos de Gran-Paso:

1. **Fork** el repositorio en el que deseas contribuir
2. **Crea una rama** para tus cambios (`git checkout -b feature/nueva-funcionalidad`)
3. **Realiza tus cambios** siguiendo las guías de estilo del proyecto
4. **Envía un Pull Request** con una descripción clara de los cambios

## Contacto
